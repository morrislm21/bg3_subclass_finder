# BG3 Subclass Quiz

A personality-based quiz that recommends Baldur's Gate 3 subclasses based on your playstyle preferences. Built for players who are new to DnD and BG3 and want a fun, approachable way to find the right class for them.

## What it does

The quiz asks 11 questions covering combat style, magic preferences, roleplay fantasy, moral alignment, and more. Each answer carries weighted values mapped to all 58 subclasses in the game (including Patch 8). At the end, subclasses are ranked from highest to lowest score based on your answers, with the top 5 results highlighted.

## Subclasses covered

All 58 subclasses across the 12 base classes:

- Barbarian, Bard, Cleric, Druid, Fighter, Monk, Paladin, Ranger, Rogue, Sorcerer, Warlock, Wizard

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- CSS Modules
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```

## Deploying

This project is configured for Vercel. Connect your GitHub repo to Vercel and it will auto-deploy on every push to main with no additional configuration required.
